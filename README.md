# CoreShift AI — product tour

Clickable tour of the working CoreShift AI product by SOA People (TR / EN / DE).
One anonymised ECC 6.0 EhP8 package is taken to S/4HANA 2023 and to S/4HANA Cloud Public Edition.

- Screens are captured from the running product; figures are its actual output for this sample package.
- Brand, customer and partner names in the sample package are anonymised; the AI model configuration is hidden.
- This repository contains only the static tour page — no product code and no customer data.
